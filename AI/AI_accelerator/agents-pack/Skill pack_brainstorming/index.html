Instalare

Trei moduri de a folosi skill-urile. Începe cu varianta 1 — e cea mai simplă.

Cel mai simplu
01

Deschide în VS Code și pornește Claude

Deschide VS Code, apoi File → Open Folder și selectează folderul skills-pack. Deschide terminalul din VS Code (Terminal → New Terminal) și scrie comanda de mai jos. Skill-urile sunt detectate automat — gata, poți lucra!

claude --dangerously-skip-permissions
02

Copiază skill-urile în alt proiect

Dacă vrei aceste skill-uri într-un proiect existent: copiază folderul .claude (cu tot ce e în el) din skills-pack și pune-l în folderul proiectului tău. Data viitoare când pornești Claude acolo, le va detecta automat.

Copiază folderul .claude/ în proiectul tău
03

Instalare globală (peste tot)

Ca să ai skill-urile disponibile în orice proiect: copiază folderele de skill-uri în locația globală Claude. Pe Windows: C:\Users\NUMELE_TAU\.claude\skills\. Pe Mac/Linux: ~/.claude/skills/.

Windows: %USERPROFILE%\.claude\skills\
